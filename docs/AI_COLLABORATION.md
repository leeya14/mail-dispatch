# AI 협업 및 기여 범위

## 제작 방식

- 지원자는 메일플러그 백엔드 채용 지원을 목표로 메일 예약 발송 프로젝트를 선택하고, 빠른 구현·서류 준비를 요청했습니다.
- Codex가 프로젝트 코드, 데모 화면, API 문서와 테스트를 작성하고 빌드·자동 테스트·로컬 SMTP 연동 검증을 수행했습니다.
- 이력서의 새 프로젝트는 'AI 협업 제작'으로 표시했습니다. 이후 직접 수정하거나 검증한 내용은 커밋과 테스트 결과를 통해 이어서 기록할 수 있습니다.

## 이번 작업에서 실제 검토한 내용

| 항목 | 반영 내용 | 확인 방법 |
|---|---|---|
| 중복 생성 | 사전 조회뿐 아니라 DB UNIQUE 제약으로 동시 요청 조정 | 8개 동시 요청이 같은 ID·레코드 1개로 수렴 |
| 키 재사용 | 같은 키에 다른 내용이면 409 | 서비스 테스트·실제 HTTP |
| 취소 경쟁 | 선점/취소에 행 잠금, PROCESSING 취소 거부 | 발송 중 취소·동시 작업자 테스트 |
| 느린 SMTP | SMTP 호출을 DB 트랜잭션 밖으로 분리 | 코드 구조 및 테스트 |
| 오류 복구 | SMTP 4xx/연결 오류 재시도, 5xx/인증 오류 중단 | 분류 테스트 및 실제 451 후 수신 |
| 결과 과장 방지 | 최종 배달 대신 SMTP_ACCEPTED 상태 사용 | API·화면·문서 용어 통일 |
| 테스트 환경 | Mockito self-attach 실패를 subclass mock maker 설정으로 해결 | 전체 27개 테스트 통과 |

## 남아 있는 검증 범위

H2 기반 자동 테스트와 로컬 SMTP 수신만 검증했습니다. MySQL 실환경·Windows 런처·실서비스 배포·부하 성능·최종 이메일 배달은 검증하지 않았습니다.
SMTP 접수 후 응답 유실 및 DB 결과 저장 실패 시 발생할 수 있는 중복/불확실 상태는 README에 명시했습니다.
